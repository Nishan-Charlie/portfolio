Project Title:
 Multi-Document Event-Level Summarization for Sinhala News 
Small Description:
This research proposes a framework for automatically generating concise summaries of Sinhala news events by grouping multiple news articles that report the same event. The framework collects news articles from multiple Sinhala news websites through web scraping, preprocesses the text, classifies events using Sinhala-BERT, groups semantically related articles using UMAP and HDBSCAN with hierarchical event clustering, and generates event-level extractive summaries using the TextRank algorithm. The system is evaluated using classification metrics (Accuracy, Precision, Recall, F1-score), clustering quality (Silhouette Score), and manual human evaluation of the generated summaries.

Project Title:
Sinhala Sarcasm Detection Using Mamba State Space Model: A Comparative Study with Transformer-Based Models
Small Description:
This research investigates the effectiveness of the Mamba State Space Model for sarcasm detection in Sinhala, a low-resource language, and compares its performance with transformer-based pretrained language models, namely SinhalaBERTo, IndicBERT, and mBERT. Sarcasm detection is a challenging Natural Language Processing (NLP) task because the intended meaning of a statement often differs from its literal interpretation, making conventional sentiment analysis methods less effective. Using an annotated dataset of approximately 3,000 Sinhala YouTube comments, the study develops a custom Mamba-based sequence classification model and fine-tunes three transformer-based models for binary sarcasm classification. The models are evaluated using standard classification metrics, including accuracy, precision, recall, Macro F1-score, Weighted F1-score, and confusion matrices. The findings demonstrate that SinhalaBERTo achieves the highest performance due to its language-specific pretraining, while the proposed Mamba model outperforms mBERT and shows that State Space Models are a feasible alternative for Sinhala NLP tasks. This study contributes to the limited body of research on Sinhala sarcasm detection and provides empirical evidence on the applicability of Mamba-based architectures for low-resource language processing.

Title:
A Cloud-Native Dynamic Pricing Engine for Shared Public-Private Parking Ecosystems Using Demand Forecasting
Summary:
This study proposes a cloud-native dynamic pricing framework using historical parking transactions, weather, and event data to forecast demand and optimize parking prices. Seven forecasting models- Histogram Gradient Boosting Regressor, XGBoost Regressor, Random Forest Regressor, LSTM, CNN-LSTM, LSTM-GRU, and Transformer were evaluated using forecasting accuracy, revenue, price stability, and operational fairness metrics. Results showed different strengths across models, while the Transformer achieved the best overall operational performance. The deployed cloud solution achieved a 100% API success rate, demonstrating practical feasibility for real-world parking management.

Name : Tharindu Darshana Rathnasuriya
Title : Enhancing Temporal Consistency in Audio-visual Segmentation
Description
This research studies a common problem in Audio-Visual Segmentation (AVS) called temporal
inconsistency. Temporal inconsistency happens when a model produces different and unstable
segmentation masks from one video frame to the next, causing flickering results, even when the
model appears accurate on individual frames.
The study uses AVSegFormer as the baseline model and evaluates its performance on the
AVSBench dataset, which contains both single-source (S4) and multi-source (MS3) videos. To
measure performance, four evaluation metrics are used:
mIoU and F-score to measure segmentation accuracy.
Mask Consistency Score (MCS) to measure how consistently the model performs across an
entire video.
Warp IoU to measure how smoothly predictions change between consecutive frames.
The results show that traditional accuracy metrics such as mIoU and F-score do not fully reveal
temporal instability. Although the baseline model achieves reasonable accuracy, many videos
still show inconsistent predictions across frames, especially in the more difficult multi-source
setting.
To improve temporal consistency, four different methods are tested:
Temporal Self-Attention – uses information from neighboring frames to improve feature
representations.
Recurrent Query Propagation – passes object-related information from one frame to the next
through the decoder.
Flow-Warped Consistency Loss – adds a training loss that encourages predictions to remain
consistent between frames using optical flow.
Recurrent Query with Auxiliary Cross-Frame Supervision – extends Method 2 by adding an
extra training objective that helps predict future-frame masks.
Among all methods, Recurrent Query Propagation performs the best. It improves both
segmentation accuracy and temporal consistency, especially on the challenging multi-source
dataset. The results suggest that directly incorporating temporal information into the model
architecture is more effective than simply smoothing features or adding consistency-based
training losses.

Title: Balancing Privacy, Accuracy, and Fairness: A Comparative Study of Privacy-Preserving Techniques in Pedestrian Detection Models for Public Surveillance
Description: This research investigates the privacy-utility trade-off in public surveillance by conducting a comprehensive comparative analysis of image anonymization techniques, including Gaussian blurring, pixelation, masking, and a novel Pose-Conditioned Silhouette (PCS) approach. The study evaluates how these methods influence the performance of both convolutional (YOLOv8) and transformer-based (RT-DETR) object detection models on the WiderPerson dataset. By quantifying privacy protection through the Structural Similarity Index (SSIM) and measuring detection accuracy via standard metrics like mAP50, the project aims to identify optimal anonymization strategies that balance personal privacy with the operational requirements of pedestrian detection.
